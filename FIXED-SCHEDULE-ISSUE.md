# Schedule Issue - Fixed ✅

## What Happened

1. User asked if "Always" entry for Sylvia Moore existed
2. Found it was in `schedule-parsed.csv` but NOT in `schedule.csv`
3. We copied `schedule-parsed.csv` → `schedule.csv`
4. **This broke everything** - dances were assigned to wrong people, awards missing

## The Problem

- The Excel parser (`parse-xlsx-final.js`) has data parsing issues
- It incorrectly assigns dancers to routines
- The manually-created `schedule.csv` was the correct, working version

## The Fix

1. ✅ Restored `schedule.csv` from `schedule.csv.bak` (the working backup)
2. ✅ Manually added the missing "Always" entry:
   ```csv
   Sylvia Moore,Saturday,10:36 AM,Room B,1652,Always,Solo,PT 9-11
   ```
3. ✅ Updated parser to NOT auto-copy (added warning instead)
4. ✅ Created documentation warning NOT to use the Excel parser

## Current Status

**Working Files:**
- `public/schedule.csv` - **This is the correct, working file** (now includes "Always")
- `public/schedule.csv.bak` - Backup from before the mishap

**DO NOT USE:**
